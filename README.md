# Oden website

Public, buildless English/Chinese product website, support page, privacy policy, and scoped internal performance notes. This repository contains marketing assets only, not the application source.

Hosted with GitHub Pages from the root of `main`. No installation or build is required. Preview with `python3 -m http.server 8765` from this directory.

Support is exclusively through this repository's public GitHub Issues. Do not publish private documents or contact details.

Screenshots depict the actual Oden interface with illustrative projects. The product is not available for download here. Update launch availability and the App Store link only after release. Review the privacy policy when application data practices change.
