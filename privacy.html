Privacy policy隐私政策

Effective: October 22, 2026 · Publisher: Jiachen Bao生效日期：2026 年 10 月 22 日 · 开发者：包家琛

This policy covers the current Mac version of OdenMap and this official website. It does not describe an unreleased iOS version. We will update it before introducing materially different data practices.本政策适用于 OdenMap 当前 Mac 版本及本官网，不代表尚未发行的 iOS 版本。引入实质不同的数据处理方式前，我们会更新政策。

Your documents stay under your control文稿由你掌握

OdenMap does not require an OdenMap account and does not automatically upload your maps or attached resources to a developer-operated server. Documents are saved where you choose. Preferences, resource references, previews, and working caches are stored locally as needed for editing. OdenMap does not include developer-operated advertising, behavioral analytics, or automatic crash-reporting services.OdenMap 无需专属账号，不会自动把导图或附件上传至开发者运营的服务器。文稿保存到你选择的位置；偏好设置、资源引用、预览及工作缓存根据编辑需要保存在本地。应用不包含开发者运营的广告、行为分析或自动崩溃报告服务。

If you save a document in iCloud Drive or another synced folder, synchronization is handled by that provider under its terms and privacy policy. External file links may require access to the original location. These are not OdenMap-operated cloud storage services.若你把文稿保存到 iCloud Drive 或其他同步文件夹，同步由该服务商按其条款与隐私政策处理。外部资源链接可能需要访问原始位置；这些不是 OdenMap 自营云存储服务。

Optional system integrations可选系统联动

Calendar and Reminders access is requested only for corresponding features. With your permission, OdenMap reads and writes the items needed for your chosen associations, such as titles, notes, dates, alarms, and links. Those items may be synced by your system calendar or reminder accounts. You can revoke access in macOS System Settings. Existing items remain in the system apps until you remove them there.日历与提醒事项权限仅用于相应功能。授权后，OdenMap 会读取或写入你选择关联所需的条目，例如标题、备注、日期、提醒与链接。系统账户可能同步这些条目。你可在 macOS 系统设置中撤销权限；已创建的条目会保留，直到你在系统应用中删除。

When you search for a reminder location, the entered place query is sent to Apple's map service. This feature does not require OdenMap to request your device's current location.搜索提醒事项地点时，输入的地点查询会发送给 Apple 地图服务。此功能不要求 OdenMap 获取设备当前定位。

External content and links外部内容与链接

HTML or Markdown resources can contain remote images, fonts, scripts, or other external content. Previewing such resources can contact their providers, revealing information such as your IP address and requested content. WebKit previews may keep website data according to the preview mode. Opening a link uses the relevant system app or browser. The external service's privacy policy applies; do not preview untrusted content.HTML 或 Markdown 资源可能包含远程图片、字体、脚本或其他外部内容。预览时可能联系对应服务商，并向其提供 IP 地址和请求内容等信息。WebKit 预览可能按预览模式保留网站数据。打开链接由相应系统应用或浏览器处理，适用外部服务的隐私政策；请勿预览不可信内容。

Purchases and system diagnostics购买与系统诊断

Apple processes App Store purchases, payment information, and refunds. OdenMap does not process or receive your card details. macOS and Apple may collect or share diagnostics according to your system settings and Apple's privacy policy.App Store 的购买、支付信息与退款由 Apple 处理，OdenMap 不处理或接收银行卡信息。macOS 与 Apple 可能依照系统设置及 Apple 隐私政策收集或分享诊断信息。

This website and support官网与反馈

This website uses no developer-added analytics, tracking cookies, advertising, or third-party fonts. Your language and appearance choices are saved in this browser’s local storage. The public beta invitation opens Apple’s TestFlight service. It is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes, as described in its Pages documentation and privacy statement.官网不添加开发者分析工具、追踪 Cookie、广告或第三方字体，语言和外观选择保存在当前浏览器的本地存储中；公开测试邀请会打开 Apple 的 TestFlight 服务。官网使用 GitHub Pages 托管。GitHub 会为安全目的记录访问者的 IP 地址，详见其 Pages 说明与隐私声明。

Support is provided through TestFlight beta feedback and GitHub Issues. Reports, your GitHub profile, and anything you attach are public and processed by GitHub. The developer uses reports to investigate issues and improve OdenMap. Do not submit sensitive information or private documents. GitHub account and content management are governed by GitHub's policies.支持入口为 TestFlight 测试反馈和 GitHub Issues。反馈、GitHub 资料及附件公开可见，并由 GitHub 处理。开发者使用反馈排查问题和改善 OdenMap。请勿提交敏感信息或私人文稿；GitHub 账户及内容管理适用 GitHub 的政策。

Retention and choices保留与控制

Your saved documents remain until you delete them from their saved locations. You can remove resources, delete local files, and revoke system permissions. Removing OdenMap does not automatically remove documents saved outside its container or items created in Calendar and Reminders. Local caches and website data can remain while the app is installed. For a general privacy inquiry or a request concerning information you voluntarily posted, open a GitHub issue without adding personal details; manage or remove your own public posts through GitHub when possible.保存的文稿会保留，直到你从保存位置删除。你可移除资源、删除本地文件或撤销系统权限。卸载 OdenMap 不会自动删除容器外文稿，也不会删除日历或提醒事项条目。应用安装期间，本地缓存和网站数据可能保留。一般性隐私咨询或涉及你主动发布的信息，可通过 GitHub Issues 提出，但不要补充个人资料；可自行通过 GitHub 管理或移除公开帖子。

Changes and contact更新与联系

Updates will be published here with a revised effective date. Contact the developer using the GitHub issue tracker. No public email or telephone support is provided.政策更新会在本页发布，并修改生效日期。请通过 GitHub Issues 联系开发者；不提供公开邮箱或电话支持。
