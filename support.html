Oden / Support支持

Let's keep your ideas moving.让思路，继续向前。

Questions, bugs, and feature requests are welcome through our public GitHub issue tracker. Oden does not require an account; a GitHub account is required to post an issue.使用问题、缺陷与功能建议，请通过公开的 GitHub Issues 反馈。Oden 本身无需注册账号；发布反馈需要 GitHub 账号。

Report an issue on GitHub →前往 GitHub 反馈 →

Issues are public. Do not upload private documents, contact details, passwords, or purchase receipts. Use an anonymized example and redact screenshots before sharing.反馈内容公开可见。请勿上传私人文稿、联系方式、密码或购买凭证；请使用匿名示例，并遮盖截图中的敏感信息。

Before reporting a bug反馈问题时

Include your Oden version, macOS version, the steps to reproduce, and what you expected versus what happened. For a performance issue, mention document size, visible node count, resource types, and your Mac model. Never replace your only copy of a document while troubleshooting.请提供 Oden 版本、macOS 版本、复现步骤、预期行为与实际结果。性能问题请补充文稿规模、可见节点数、资源类型和 Mac 型号。排查时，请保留文稿的原始备份。

Where is the user guide?如何查看使用手册？

Use Oden's Help menu to open its native help book. It supports offline reading and search, with English and Chinese topics. Keyboard shortcuts can be reviewed in Oden's shortcut settings.从 Oden 的“帮助”菜单打开原生帮助书，支持离线阅读与搜索，提供中英文主题。可在应用的快捷键设置中查看与调整可配置的按键。

Can a mind map be a node?思维导图也能成为节点吗？

Yes. Supported imported map files can appear as resource previews within a parent map. This is a map-of-maps workflow, not an editor for every nested level inside the resource card. Supported documents can also be attached above an ordinary text topic. File previews and paging depend on the format and embedded preview available in the file.可以。受支持的导图文件能够作为资源预览，放进另一张导图，形成“导图中的导图”。这不等于在卡片内编辑任意层嵌套导图。受支持文稿也能附在普通文字主题上方；预览和翻页能力取决于格式及文件内的预览内容。

Does Oden require Calendar or Reminders access?必须授权日历与提醒事项吗？

No. These integrations are optional. Permissions are requested when you use the corresponding features. You can manage access in macOS System Settings. Basic mind mapping does not depend on these permissions.不需要。这些是可选联动功能，仅在使用相应功能时申请权限。可在 macOS 系统设置中管理授权；普通思维导图编辑不依赖这些权限。

Availability and purchases发行与购买

The Mac App Store launch is being prepared. Oden is planned as a one-time purchase, not a subscription. Final availability, price, and system requirements will be shown in the App Store. An iOS version is planned but is not available yet; no release date is promised. Apple handles purchases and refunds under its own policies.Mac App Store 首发正在准备中。Oden 计划采用买断制，而非订阅。最终售价、发行范围与系统要求，以 App Store 为准。iOS 版本计划后续推出，目前尚未发行，也未承诺具体日期。购买和退款由 Apple 按其政策处理。
