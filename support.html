HERE TO HELP为你解答

A little clarity.多一点了解。

Questions, feedback, or a good idea for OdenMap? Start here.关于 OdenMap 的疑问、反馈，或一个好想法，都可以从这里开始。

How do I join the beta?如何加入测试？

Open the public TestFlight invitation on a Mac running macOS 14 or later. Install TestFlight, sign in with your Apple Account and accept the invitation. The public group allows up to 5,000 testers. The iPhone and iPad versions are coming soon; this invitation currently covers the Mac app.使用 macOS 14 或更新系统的 Mac，打开TestFlight 公开邀请，安装 TestFlight，登录 Apple 账户后接受邀请。公开测试组上限为 5,000 人。iPhone 与 iPad 版本即将推出，目前此邀请提供的是 Mac 版本。

Where can I send feedback?如何反馈问题？

Use TestFlight feedback for beta crashes and screenshots, or open a GitHub issue. Include your macOS version, Mac model, a short description and steps to reproduce. Keep a backup before testing. Public issues are visible to everyone: do not attach private documents or personal details.测试版的崩溃和截图可通过 TestFlight 反馈，也可以提交 GitHub Issue。请提供 macOS 版本、Mac 型号、问题描述及复现步骤，并在测试前保留文稿备份。公开 Issue 对所有人可见，请勿附上私人文稿或个人信息。

Where is the user guide?在哪里查看使用手册？

Choose Help > OdenMap User Guide in the Mac app. The native help book supports offline reading and search in English and Chinese. Customizable shortcuts are in OdenMap > Settings > Keyboard Shortcuts.在 Mac 应用中选择“帮助”>“OdenMap 使用手册”。原生帮助书支持中英文离线阅读与搜索；可调整的快捷键位于“OdenMap”>“设置”>“快捷键”。

Is OdenMap native?OdenMap 是原生应用吗？

Yes. OdenMap is built with Swift, SwiftUI and AppKit for the Mac. Apple Silicon and Intel Macs are supported on macOS 14 or later. iOS and iPadOS versions are in development.是的。OdenMap 使用 Swift、SwiftUI 与 AppKit 开发，支持运行 macOS 14 或更新系统的 Apple Silicon 和 Intel Mac。iOS 与 iPadOS 版本正在开发中。

Can a mind map be a node?思维导图也能成为节点吗？

Supported map files can appear as resource previews inside another map. You can also attach supported resources above an ordinary text topic. Preview and paging depend on the file format; a resource preview is not an editor for every nested map.受支持的导图文件可以作为资源预览放入另一张导图，也可以把受支持的资源嵌入普通文字节点上方。预览和翻页能力取决于格式；资源预览不等于在卡片内编辑任意层级的嵌套导图。

Are Calendar and Reminders required?必须授权日历与提醒事项吗？

No. These integrations are optional. Basic mind mapping does not depend on these permissions. Manage granted access in macOS System Settings.不需要。这些联动是可选功能，普通思维导图编辑不依赖此类授权。已授予的权限可在 macOS 系统设置中管理。

Availability and purchases发行与购买

The Mac app is in public beta on TestFlight. A one-time purchase is planned for the App Store release; final pricing and availability will be listed there. iPhone and iPad versions are coming soon, with no specific release date announced. Apple handles purchases and refunds under its policies.Mac 应用目前通过 TestFlight 公开测试，计划在 App Store 正式版采用买断制，最终价格与发行范围以 App Store 为准。iPhone 与 iPad 版本即将推出，尚未公布具体日期。购买和退款由 Apple 按其政策处理。
